L'histoireThe story

nom · danoisnoun · Danish

Meuble. Le mot du pays où tout a commencé, et le nom de ce projet.

A piece of furniture. The word from the country where it all started, and the name of this project.

  1. Une date de départA date to leave

    Mon stage au Danemark se terminait le 20 novembre. Lit, matelas, télé, micro-ondes, chaises : tout un appartement devait trouver preneur avant que je prenne l'avion.

    My internship in Denmark ended on 20 November. Bed, mattress, TV, microwave, chairs: a whole flat had to find new owners before my flight.

  2. Une porte ferméeA closed door

    Au Danemark, on vend ses meubles sur le site d'annonces local. Sauf que, comme beaucoup de gens de passage, je n'y avais pas accès. Il fallait trouver les acheteurs autrement.

    In Denmark, people sell furniture on the local classifieds site. Like many people just passing through, I couldn't use it. The buyers had to be found another way.

  3. La force des groupes d'expatsThe power of expat groups

    Je les ai trouvés dans les groupes Facebook d'étrangers et d'étudiants : chaque semaine, quelqu'un arrive et doit tout racheter. Mais vingt annonces postées une par une, ce sont vingt posts noyés dans le fil. Il me fallait un seul lien : tout l'inventaire, les photos, les prix, et un bouton pour réserver.

    I found them in Facebook groups for internationals and students: every week someone new arrives and needs everything. But twenty listings posted one by one are twenty posts lost in the feed. I needed a single link: the whole inventory, photos, prices and a button to book.

  4. Une affiche dans le hallA poster in the hallway

    Les voisins passent devant la porte d'entrée tous les jours. Une affiche A4, la liste des prix, un QR code : on scanne, on voit tout, on choisit un créneau.

    Neighbours walk past the front door every day. An A4 poster, a price list, a QR code: scan, see everything, pick a time.

  5. Et partout ailleursAnd everywhere else

    Un meuble est aussi sur Marketplace, DBA, Leboncoin ou Vinted ? Sa fiche renvoie vers ces annonces. La boutique devient la vitrine qui relie tout le reste.

    Is an item also on Marketplace, DBA, Leboncoin or Vinted? Its card links there. The shop becomes the window that ties everything together.

Chaque phrase existe en plusieurs tournures. Un petit hash déterministe choisit laquelle à partir du numéro de version de l'annonce : la même annonce garde son texte, « Reformuler » change juste le numéro. Et le prix payé neuf fait apparaître l'économie.

Every sentence comes in several wordings. A small deterministic hash picks one from the listing's version number: the same listing keeps its text, "Rephrase" just changes the number. And the price paid new turns into a saving.

index.htmlVoir sur GitHub ↗View on GitHub ↗
// Choisit une des tournures, toujours la même pour un même numéro de
// version et une même place dans le texte (`slot`).
function pick(options, version, slot) {
  let h = Math.imul(version | 0, 0x9e3779b1);
  for (let i = 0; i < slot.length; i++) h = Math.imul(h ^ slot.charCodeAt(i), 0x01000193);
  h ^= h >>> 15;
  return options[(h >>> 0) % options.length];
}

L'affiche est un composant React imprimé tel quel. Le QR code est dessiné par qrcode.js dans un div jetable, puis converti en image : il suit l'adresse de la page, donc il marche aussi sur ton fork sans rien changer.

The poster is a React component printed as is. The QR code is drawn by qrcode.js into a throwaway div, then turned into an image: it follows the page's address, so it works on your fork with no changes.

// QR code en image, dessiné par qrcode.js dans un div jetable.
function useQrCode(text) {
  const [src, setSrc] = useState(null);
  useEffect(() => {
    if (!text || typeof QRCode === 'undefined') { setSrc(null); return; }
    try {
      const box = document.createElement('div');
      new QRCode(box, {
        text, width: 512, height: 512,
        colorDark: '#16307a', colorLight: '#ffffff',
        correctLevel: QRCode.CorrectLevel.M,
      });
      const canvas = box.querySelector('canvas');
      setSrc(canvas ? canvas.toDataURL('image/png') : null);
    } catch { setSrc(null); }
  }, [text]);
  return src;
}

Supabase met en pause les projets gratuits restés une semaine sans activité. Une GitHub Action lit une ligne chaque matin : le projet reste éveillé, gratuitement. Si ça échoue, GitHub prévient par e-mail.

Supabase pauses free projects after a week without activity. A GitHub Action reads one row every morning: the project stays awake, for free. If it fails, GitHub sends an email.
